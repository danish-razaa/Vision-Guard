Production vs. Research Path

The approved RandomForest model utilizes 45 canonical features and serves as the primary production engine. The five selectable candidate models use 65 features from the 3,500-sample research dataset.

Leakage Prevention Guarantee

Clean images and all corresponding manipulated variants share a strict base_id. Partitioning with GroupShuffleSplit guarantees that no single image source ever leaks across train, validation, and test splits.

Threshold Calibration Logic

Thresholds are not arbitrary 50% assumptions. Each model enforces an artifact-stored threshold mathematically optimized on held-out validation sets to suppress false alarms on authentic photos.

Scientific Boundary & Scope

Generated samples simulate controlled prompt-conditioned perturbations. They represent rigorous defensive input-level security benchmarks, rather than unconstrained gradient attacks against proprietary remote APIs.
