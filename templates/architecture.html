Production path

The approved RandomForest uses 45 saved features and remains the default scanner selection.

Development path

Five selectable candidates use 65 features from the expanded experiment. They remain explicitly labeled experimental because they were not promoted.

Leakage prevention

Each clean image and its manipulated versions share a base_id and remain in the same train, validation, or test split.

Scientific boundary

Generated samples are controlled prompt-conditioned perturbation simulations, not genuine optimized attacks against an external VLM.
